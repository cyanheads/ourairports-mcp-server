# 0.3.0 — 2026-11-10

## Added

- Serve the OurAirports caller guide at `skill://ourairports-guide/SKILL.md`.
- **Search and find tools** accept `offset` and return `nextOffset` when more rows remain. Reuse the same query and data snapshot to continue. ([#27](https://github.com/cyanheads/ourairports-mcp-server/issues/27))
- **`ourairports_search_runways`** accepts a coordinate pair and optional radius, ranks by distance to the parent airport, and returns that distance and bearing. The `surface` filter accepts one substring or an array matched with OR. ([#29](https://github.com/cyanheads/ourairports-mcp-server/issues/29))
- **`ourairports_find_navaids`** accepts an exact, case-insensitive `ident` and pages through all matching facilities in dataset order. ([#30](https://github.com/cyanheads/ourairports-mcp-server/issues/30))
- **Airport and runway records** expose recorded airport keywords, website and Wikipedia links in airport details, and runway-end center coordinates and elevations. ([#31](https://github.com/cyanheads/ourairports-mcp-server/issues/31))
- **Agent Plugins** can discover the server through root `plugin.json` and `mcp.json` manifests.

## Changed

- **Page limits** above the tool ceiling clamp with a notice. Set `OURAIRPORTS_CLAMP_LIMITS=false` to reject oversized limits. ([#27](https://github.com/cyanheads/ourairports-mcp-server/issues/27))
- **`ourairports_find_airports` and `ourairports_find_navaids`** accept coordinate searches up to 20,016 km, including antipodal results. ([#28](https://github.com/cyanheads/ourairports-mcp-server/issues/28))
- **Claude Desktop bundles** include the caller guide and omit development files.

## Fixed

- **`ourairports_search_airports`** matches exact IATA, ICAO, GPS, local codes, and idents and ranks their holders first on code-only queries. Name searches recognize `intl`, `rgnl`, `muni`, `fld`, and `mem`. ([#26](https://github.com/cyanheads/ourairports-mcp-server/issues/26))
- Keep distances finite at antipodes so rounding cannot exclude valid results from coordinate searches. ([#28](https://github.com/cyanheads/ourairports-mcp-server/issues/28))
- Preserve intraword underscores next to supplementary Unicode letters or digits in Markdown output on Node.js.
