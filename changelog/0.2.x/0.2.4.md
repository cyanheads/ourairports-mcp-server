# 0.2.4 — 2026-09-23

## Added

- **Navaid service-volume fields** — `ourairports_find_navaids` rows carry `usageType`, `power`, `magneticVariationDeg`, `slavedVariationDeg`, and `dmeFrequencyKhz` as recorded upstream, `null` where empty ([#18](https://github.com/cyanheads/ourairports-mcp-server/issues/18)).
- **Runway displaced thresholds** — every runway carries `leDisplacedThresholdFt` / `heDisplacedThresholdFt` (`null` when none is recorded); `lengthFt` and `min_length_ft` are described as the full surface length, not usable takeoff or landing distance ([#13](https://github.com/cyanheads/ourairports-mcp-server/issues/13)).

## Changed

- **Shared-code `resolutionNote`** — names every other airport carrying the code (ident, country, code space) and whether resolution priority or dataset row order picked this one; shared by `ourairports_get_airport`, `airport://{code}`, and a new optional `resolutionNote` in `ourairports_find_navaids` airport mode ([#15](https://github.com/cyanheads/ourairports-mcp-server/issues/15)).
- **Docs** — README and `docs/design.md` cover the new fields and behavior, with corrected dataset statistics and scan timings.

## Fixed

- **`totalCount` on `ourairports_find_airports` / `ourairports_find_navaids`** counts matches before `limit`, with `truncated` / `shown` / `cap` disclosure and recovery guidance; text headings show the returned count ([#11](https://github.com/cyanheads/ourairports-mcp-server/issues/11)).
- **Navaid `frequencyMhz`** is keyed on navaid type — VOR/VOR-DME frequencies and DME/TACAN/VORTAC paired frequencies carry MHz, NDB and NDB-DME read `null` — and upstream `-1` placeholder frequencies read `null` ([#14](https://github.com/cyanheads/ourairports-mcp-server/issues/14)).
- **`content[]` text** renders coordinates at full stored precision and Markdown-escapes upstream text; `structuredContent` keeps the raw values ([#17](https://github.com/cyanheads/ourairports-mcp-server/issues/17)).
