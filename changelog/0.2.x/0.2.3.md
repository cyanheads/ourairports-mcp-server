# 0.2.3 — 2026-09-19

## Added

- **CodeQL workflow** — `.github/workflows/codeql.yml` is the repository's sole GitHub Actions workflow.
- **Server config regression tests** — blank and unsubstituted MCPB `OURAIRPORTS_DATA_DIR` values resolve as unset; an explicit directory is preserved.

## Changed

- **HTTP session default** — With MCP_SESSION_MODE unset, HTTP starts stateless; an explicit value still overrides the default.
- **Tool input handling** — Core 0.13.4 accepts unambiguous argument-key aliases, ignores client-added root metadata, and repairs JSON-stringified array inputs when validation succeeds afterward; the six advertised input schemas remain unchanged.
- **Tool error guidance** — Core 0.13.3 adds a reason and recovery hint to invalid arguments; 0.13.5 includes reason and retryability in error text where supplied. Rejected arguments use the `InvalidParams` envelope introduced in 0.12.7.
- **Environment parsing** — `getServerConfig()` uses core 0.13.0 normalization for empty strings and whole-value `${…}` placeholders instead of a local Zod preprocess guard.
- **Development skills** — the project skill tree moves from `skills/` to `framework-skills/`, with references and sync checks updated. Integrations that read the old development path must follow the new one.
- **Runtime floor** — Bun 1.4.0 or later is required; Node 24 or later remains supported.
- **Project tooling and metadata** — copied build, devcheck, lint, packaging, and skill-sync scripts are refreshed; plugin metadata, issue forms, contributor guidance, and the README reflect the current package and tool surface.
