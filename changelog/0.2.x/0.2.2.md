# 0.2.2 — 2026-08-24

## Added

- **Public cache hints** — Tool, prompt, resource, template, and server discovery catalogs plus `airport://{code}` advertise a one-day public cache lifetime to 2026-07-28 clients; earlier protocol revisions are unchanged.
- **Contract coverage** — Smoke, integration, and fuzz suites exercise all six tools and the airport resource, including both `ourairports_find_navaids` modes and their existing `mode_conflict` error contract.
- **Community health files** — Contributor guidance and a code of conduct join the repository metadata.

## Changed

- **Protocol and SDK compatibility** — `@cyanheads/mcp-ts-core` now runs on MCP SDK v2 and serves 2026-07-28 and 2025-06-18 clients from the same six-tool, one-resource surface.
- **Input and error contracts** — Tool schemas reject undeclared root input fields by name while valid calls remain unchanged; structured error envelopes are advertised alongside successful outputs.
- **HTTP session mode** — `.env.example`, the Docker image, `server.json`, and the README explicitly select `stateless`; `auto` remains documented as the schema default and resolves to stateful.
- **Build and packaging** — Bun 1.4, TypeScript 7, split typecheck/build configs, current framework scripts and skills, MCPB native-binding cleanup, and package metadata are synchronized.
- **Security contact** — Vulnerability reports use `security@caseyjhand.com`.
