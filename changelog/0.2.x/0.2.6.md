# 0.2.6 — 2026-10-18

## Changed

- **Country-scoped discovery** — `ourairports_list_countries` accepts `country`, combines it with `continent`, and nests regions by their recorded country association ([#12](https://github.com/cyanheads/ourairports-mcp-server/issues/12)).
- **Human-readable titles** distinguish all six tools and the Airport Record resource ([#22](https://github.com/cyanheads/ourairports-mcp-server/issues/22)).
- **Build and development guidance** — Bun images and `packageManager` use 1.4.3; framework skills and agent references are synced, releases use gated PRs, and the README overview is shorter.

## Fixed

- **Country/region filters** validate source-compatible code shapes and bundled membership on both search tools, with discovery guidance for unknown codes. Literal empty strings are unset; padded codes and valid empty selections remain accepted. Data refreshes reject inaccessible facets before writing ([#16](https://github.com/cyanheads/ourairports-mcp-server/issues/16)).
- **Bounded search selection** retains at most `limit` airport candidates and runway rows while counting every match, preserving ranking, dataset-order ties, and runway order ([#20](https://github.com/cyanheads/ourairports-mcp-server/issues/20)).
- **Navaid mode errors** name the missing coordinate for incomplete pairs, including pairs combined with `airport_code`, while retaining the declared error code, reason, and recovery ([#23](https://github.com/cyanheads/ourairports-mcp-server/issues/23)).
